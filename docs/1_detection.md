# Pipeline Step 1: Detection (SAHI + RT-DETR)

## Architectural Overview
The detection module (`src/detection.py` and `src/sahi_rtdetr_detection.py`) is responsible for translating raw RGB pixels into bounding boxes. 

Because drone footage suffers from extreme scale variation (a bus might be 150 pixels long, while a pedestrian is 8 pixels wide), feeding a 4K frame directly into a 640x640 detection network results in immediate catastrophic failure for small objects. 

We solve this using **SAHI (Slicing Aided Hyper Inference)** paired with a heavy Transformer-based backbone (**RT-DETR-X**) or **YOLOv8**, effectively magnifying the spatial resolution of the image dynamically.

---

## 1. SAHI Tiling Architecture (`src/tiling.py`)
Instead of resizing the 1920x1080 video frame into a 1280x1280 network tensor (which destroys fine details), SAHI dynamically slices the image.

### Grid Setup
By default, the pipeline generates a `3x3` grid across the 1920x1080 frame.
Each tile is exactly `640x360` pixels in original resolution.
When this tile is passed to the detector and upscaled to `imgsz=1280`, a 10x5 pixel motorcycle is mathematically magnified to **35x17 pixels**. This pushes the motorcycle well past the network's minimum spatial resolution limit.

### Overlap Matrix
If we used a hard grid, any vehicle crossing a boundary would be sliced in half and lost. 
To prevent this, the grid slices overlap by exactly `20%` (configurable via `--tile-overlap 0.20`).
- A `1920` width frame divided into 3 columns with `20%` overlap results in tiles of width `~768 px`.
- Stride = `768 * (1.0 - 0.20) = 614 px`.
This ensures that the center of any vehicle is always fully encompassed by at least one tile.

---

## 2. RT-DETR-X (Real-Time DEtection TRansformer)
While YOLOv8 is an anchor-free CNN, the pipeline defaults to `rtdetr-x.pt` (the largest Real-Time DETR model) for maximum precision in dense crowds.
- **Why Transformer?**: CNNs rely on Non-Maximum Suppression (NMS) during the internal network pass. In dense Indian traffic, NMS aggressively deletes overlapping bounding boxes, completely erasing motorcycles driving right next to cars.
- **Set Prediction**: RT-DETR uses a bipartite matching loss and self-attention blocks. It outputs a fixed set of predictions without requiring internal NMS, natively preserving heavily occluded and overlapping vehicles.

---

## 3. SAHI Post-Processing Fusion (`src/sahi_fusion.py`)
Because of the 20% overlap, a vehicle situated in the overlapping zone will be detected independently by *both* Tile A and Tile B.
Once inference completes across all 9 tiles, the localized bounding boxes are mapped back to absolute global coordinates `[x1, y1, x2, y2]`.

We then apply a strict **Class-Aware NMS (Non-Maximum Suppression)** across the global pool:
- NMS IoU Threshold = `0.50` (configurable via `--iou 0.50`).
- If two boxes of the **same class** overlap by `> 0.50`, they are determined to be duplicates of the same object generated by the tile overlap. The box with the lower confidence score is discarded.
- Crucially, this NMS is *class-aware*. If a person (Class 0) overlaps by 80% with a motorcycle (Class 3), neither is suppressed.

## 4. Confidence Thresholding
The unified list of detections is filtered using a strict baseline:
`conf_threshold = 0.25` (configurable via `--conf 0.25`).
Any box below this threshold is immediately discarded to prevent noise. However, boxes above `0.10` but below `0.25` are kept in memory exclusively for **Stage 2 Tracker Association** (to recover occluded tracks), but they are never allowed to initialize new tracks.

## 5. Output Format
The final output is passed directly to the `BYTETracker` loop in the following structure:
```python
[
    {
        "bbox": [1042.5, 450.2, 1120.0, 485.8],  # Global absolute pixels
        "confidence": 0.885,                     # RT-DETR probability score
        "class_id": 2,                           # 2 = car
        "class_name": "car"
    },
    ...
]
```
